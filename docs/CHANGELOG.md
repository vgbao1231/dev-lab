# Design change log

History of revision rounds, moved out of `ROADMAP.md` so the roadmap only holds status and checklists.
Agents **do not need to read** this file unless they need to know how a value changed over time. The rationale for notable
decisions lives in [`adr/`](adr/README.md); the full history lives in `git log`.

- **2026-10-25**: The strip that covers the 12px gap above the scrolled header capsule now follows `--header-strip-bg`; the home page sets it to its own dark base so the strip no longer shows as a lighter band over the page background.
- **2026-10-25**: Removed duplicate horizontal rules on the home page: `PostList` and `ProjectList` now draw a rule only between consecutive rows (no rule under the section heading, no closing border duplicating the section rule). The header bar no longer draws its bottom border at the top of the page; the border appears with the scrolled capsule. The home background moved from `.home-wrapper` to `<body>`, and the decoration layer moved to a new layout `background` slot outside `<main>` so it continues behind the header and footer. Docs: `docs/design/layout.md`, `docs/design/components.md`.

- **2026-10-24**: Refreshed the home page following the digital garden prototype: two-column Hero layout (a visual column illustrating an SVG seedling with a mound of soil fading out into the background + a `Small steps / Big progress` note), a two-part "Các lab" section (sidebar + card grid with 72px cover, tag chips, serif title and status line); home page background with organic blobs and 65 blurred floating dust motes (`dustParticles`) moving in parallax with the mouse pointer (`mousemove`) and page scroll (`scroll`); respects `prefers-reduced-motion` and integrates fully with View Transitions. Docs: ADR 0012, `docs/design/layout.md`, `docs/design/motion.md`.
- **2026-10-24**: Added the search command palette (native `<dialog>`, `Ctrl/Cmd+K` and `/`, diacritic-insensitive search, `/search-index.json` index generated at build time, no runtime dependency added); moved `/bai-viet` to a 1/2/3-column card grid with 16:9 cover, tags and reading time; added inline SVG covers driven by tokens + monogram fallback; created the shared tag registry `@dev-lab/tags` (23 tags, 3 groups); added a shared 1.5px icon set; replaced the sample article with three React internals articles. Docs: `TAGS.md`, sections 6/7, ADR 0009–0011
- **2026-10-20**: Responsive check at 360/390/414px (light + dark): header nav wraps into two tidy rows and a single row, lab grid at one column, the TOC is a block at the top of the article, facts chips wrap without overflowing; no horizontal overflow at page level
- **2026-10-20**: Capitalised the first letter of labels that were lowercase: header nav (`Labs`, `Bài viết`, `Liên hệ`), the `Trang liên hệ` link, the GitHub label, section notes and the footer bottom row (`Mã nguồn · Deploy trên Cloudflare`); kept lowercase for handles, URLs and facts-table labels
- **2026-10-19**: Merged three width tiers into two: removed `--width-prose`, the article reading column now shares `--width-content`; lowered `--width-page` 1280px → 1120px and set the text block to 800px so the home page is less left-heavy and content fills more of the frame width
- **2026-10-17**: Initialised the roadmap, marked phase 1 as in progress
- **2026-10-17**: Set up the pnpm workspace, ESLint/Prettier/TS strict, CI. Moved the Astro project into `portal/`, added design tokens + theme switching, added `labs/react-lab`
- **2026-10-18**: Decided the ecosystem name is **Dev Lab** (repo `dev-lab`). Replaced the Balsamiq Sans display font with Patrick Hand because Balsamiq Sans lacks a Vietnamese subset
- **2026-10-18**: Split **theme** and **mode** into two independent axes (`data-theme` + `data-mode`), dropping the fixed 4-mode model. Phase 1 implements only the Minimalist Editorial theme
- **2026-10-18**: Added the content system: `posts` collection, frontmatter schema, `/bai-viet` and article detail pages, latest articles list on the home page. Checked WCAG AA contrast for Minimalist Editorial: every token pair passes AA
- **2026-10-18**: Added motion: motion tokens (section 7 of `DESIGN_SYSTEM.md`), View Transitions between pages, entrance animation via `motion/mini`, cross-fade when switching theme/mode. `data-theme`/`data-mode` survive `astro:before-swap`
- **2026-10-18**: Updated `DESIGN_SYSTEM.md` following `design-reference/`: single-column 720px layout, sections separated by rules, lab cards with 8px radius as links, theme picker as a segmented pill, eyebrow labels, data tables with row hover. Added section 7.4 hover rules (growing underline, ghost/outlined/filled/segmented button system) and noted intentional differences (keeping Patrick Hand instead of Balsamiq Sans)
- **2026-10-18**: Moved layout to two width tiers: outer frame `--width-page` 1280px, text block `--width-content` 720px (`.measure`); added base breakpoints 560/640/768/1024 and horizontal padding per breakpoint. Changed the lab grid to `auto-fit` with self-filling columns
- **2026-10-18**: Reworked the header following `ngockhoi96.dev`: sticky, blurred capsule (`backdrop-filter`) on scroll, slides out/in by scroll direction (disabled with reduced motion), accent nav pill on hover, mono brand font
- **2026-10-18**: Wired the shared-element View Transition for article titles (`view-transition-name: vt-post-<id>` in `PostList` and on the detail page). Temporarily removed the "Stack comparison" section from the home page
- **2026-10-18**: Added `transition:persist` for the header, `view-transition-name: page-title` for page titles, narrowed the page-transition cross-fade to `main` (nothing animates at the root) with a `data-theme-transition` flag so theme changes still cross-fade the whole page. Switched the theme/mode picker to two native `<select>` elements
- **2026-10-18**: Smoothed the header chrome: `backdrop-filter` always on, removed the bar height change so there is no vertical reflow, added the `--duration-chrome` 340ms token; raised the hide threshold to 320px + 16px delta + 250ms cooldown; added a "back to top" button. Widened the article reading column (`--width-prose` 800px, centred) and inset section rules to the content block width
- **2026-10-18**: Header: once scrolled, the capsule drops by 12px (variable `--header-inset`) using `position: relative; top` so there is no reflow; added an opaque `::before` background strip to cover the gap. Article detail page: added a table of contents (TOC) generated from `render()`'s `headings`, auto-marks the section being read, and a 2px reading progress bar at the top edge of the viewport
- **2026-10-18**: Article detail page becomes two columns from 1200px: reading column `--width-prose` 800px + TOC column `--width-toc` 220px stuck below the header (below 1200px it remains a block at the top of the article). Added a `#` copy-link button on each heading. Moved the reading progress bar to `animation-timeline: scroll()` (with a JS fallback that self-checks via `getComputedStyle`) to stop the jitter. Added a sticky footer (`body` flex column `min-height: 100dvh`) and the `.visually-hidden` utility. Extended the sample article to test the TOC + progress bar
- **2026-10-18**: Article TOC: reduced to **one level** (`h2`), made the active section clearer (`--color-surface` background + `--color-accent` left rule + `--color-text` text), added a slim theme/mode-aware scrollbar (token `--color-scrollbar-thumb`) and a blurred `::after` overlay at the bottom edge when sections remain below
- **2026-10-18**: Allow **multiple active TOC items at once**: every heading currently in view is marked; if no heading is in view, keep the nearest one already passed. Simplified the sample article to a single `h2` level
- **2026-10-18**: Raised the type scale by 1px at small sizes and in body text: `--text-2xs` 11→12, `--text-xs` 12→13, `--text-sm` 14→15, `--text-base` 16→17, `--text-lg` 18→19px. Left `h2` (26px) and `h1` (38px) unchanged
- **2026-10-19**: Home page becomes a portfolio: hero gains a role + three CTAs (`Xem các lab` · `Đọc bài viết` · `Liên hệ`), added an "About me" section (intro + facts table + skills) and "Other projects" (new `ProjectList`) — both hidden when there is no data. Reworked the footer into four columns (brand · Content · Lab · Contact). Added `src/data/profile.ts` as the single source for personal information; `.tag` consolidated into `global.css`
- **2026-10-19**: Adjusted the type scale per feedback: `--text-xs` 13→14 (section labels and TOC headings clearer), `--text-sm` 15→16 (Inter and JetBrains Mono side by side looked mismatched), `--text-lg` 19→21 (article titles, lab names, project names). Split out a new `--text-md` 18px token for `.lead` because it previously shared `--text-lg` with titles, making it too large in one place and too small in another. Added `--text-brand` 24px for the header brand (previously hard-coded at 22px). Updated `DESIGN_SYSTEM.md` section 4 to match the real tokens instead of the old px numbers in section 6
- **2026-10-19**: Settled the **mono rule**: JetBrains Mono text is always 2px smaller than Inter text in the same role, so all mono text sizes (nav, footer links, kicker, contact rows, code blocks, meta lines) drop 16→14px; Inter text stays 16px. Facts-table labels go to 14px to match other mono labels. Home page: the hero becomes a **greeting** (`Xin chào, tui là Gura` + slogan from the new `profile.tagline`) and the "Dev Lab" block becomes its own section right below. Header brand 24→32px with `line-height: 1`, so header height is unchanged. Facts table gains `align-items: baseline` so mono labels and Inter values sit on the same baseline
- **2026-10-19**: Third revision round: **all text links use mono** for consistency — consolidated into the `.link-row` class in `global.css` (replacing the old `.contact-row`), applied to the hero CTA, "Tất cả bài viết", the back link at the end of articles and `skip-link`; article/lab/project titles and links inside sentences keep the content font (both exceptions documented in `DESIGN_SYSTEM.md` section 4). Mono labels (eyebrow, TOC headings, facts-table labels) 14→16px. `.lead` 18→17px (`--text-base`) and the `--text-md` token **removed** as it had no users left; brand back to 28px
- **2026-10-19**: Fourth revision round: **all three** hero CTA links get an arrow `→` (previously only the first). Filled `profile.ts` with real data: added the **`slogan`** field (a personal motto, rendered as an accent-coloured `// …` note line under the hero tagline), changed the tagline to a Vietnamese sentence, added three facts rows (`Ngoại ngữ`, `Nhiên liệu`, `Ngoài code`). Documented the rule for choosing facts in `DESIGN_SYSTEM.md`: only include things that are essentially unchanging; anything that changes over time goes into `about`
- **2026-10-19**: Sixth revision round: **facts-table values become chips** — referencing the "Digital Garden" layout but choosing colours from tokens: `--color-surface` background, `--color-border` border, `--radius-lg` radius, **Patrick Hand** at `--text-base` (Inter text in the facts table was dropped because long lines made the table feel heavy like a data table). Removed leader dots and the rules between rows (used the reference image but with fewer horizontal lines). **Removed the `Vai trò` row** from the facts table — the role already appears in the Dev Lab block kicker, so repeating it was redundant; `profileFacts` now only builds `Khu vực` from `profile.location` and then appends `profile.facts`. `ProfileFact.value: string` changed to `items: string[]`, one idea per chip (`Tiếng Việt` · `Tiếng Anh · TOEIC 940`, …).
